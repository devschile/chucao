Componentes

Los componentes se renderizan acá en vivo, cargados desde el CDN (static.devschile.cl/chucao/latest/). Cada demo incluye el código de uso.

ch-accordion

@devschile/chucao/ch-accordion

Acordeón de apertura única; cada ítem es un botón accesible con panel role="region" (contenido por slot panel-<value>). Emite chChange. 

<ch-accordion id="demo-accordion"></ch-accordion>

ch-alert

@devschile/chucao/ch-alert

Mensaje de estado en bloque, con tres variantes. warning se anuncia con role="alert"; default y positive usan role="status". Definir dismiss-label agrega un botón de cierre que emite chDismiss.

Los cambios se guardan solos mientras editas. Componente publicado en el CDN. No pudimos conectar con el servidor. Este aviso se puede cerrar.

<ch-alert variant="warning">No pudimos conectar con el servidor.</ch-alert>
<ch-alert id="demo-alert" dismiss-label="Descartar aviso">Este aviso se puede cerrar.</ch-alert>

ch-modal

@devschile/chucao/ch-modal

Diálogo modal sobre el <dialog> nativo, abierto con showModal(): el navegador se encarga del foco, de marcar el resto de la página como inerte, del cierre con Escape y del backdrop. Se cierra además al hacer clic fuera del diálogo. Emite chOpen y chClose.

Abrir diálogo

¿Publicar al CDN?

Se publicará la versión actual de la librería. La acción no se puede deshacer.

 
<ch-button id="demo-modal-trigger">Abrir diálogo</ch-button>

ch-tooltip

@devschile/chucao/ch-tooltip

Texto de ayuda que aparece al pasar el mouse y al enfocar con el teclado, con cuatro posiciones. El disparador y el texto van por slot (trigger y content) para que queden en el mismo árbol: así el aria-describedby resuelve y el texto llega a los lectores de pantalla. El disparador debe ser un elemento nativo enfocable.
